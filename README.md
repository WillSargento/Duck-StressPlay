# 🦆 Duck StressPlay

Jogo de plataforma 2D desenvolvido no **Construct 3** como projeto de estudo em desenvolvimento de jogos.

## 🎮 Sobre o projeto

**Duck StressPlay** é um jogo de plataforma 2D no qual o jogador controla um pato através de diferentes fases, enfrentando obstáculos, armadilhas e desafios até alcançar o objetivo de cada nível.

O projeto teve início a partir de um projeto-base desenvolvido durante as aulas e posteriormente foi modificado e expandido como parte do meu processo de aprendizado em desenvolvimento de jogos.

Durante o desenvolvimento, trabalhei na adaptação de elementos do projeto original, criação e modificação de fases e implementação de novas ideias e mecânicas.

## 🕹️ Mecânicas

O jogo trabalha conceitos como:

- Movimentação do personagem
- Plataformas e obstáculos
- Armadilhas
- Progressão entre fases
- Coleta e interação com objetos
- Sistema de desbloqueio
- Efeitos sonoros
- Condições de vitória e progressão

## 🛠️ Tecnologias e ferramentas

- **Construct 3**
- Sistema de eventos do Construct 3
- Desenvolvimento de jogos 2D
- Pixel Art / Sprites 2D
